# 1.25.10 版变更记录（2026-11-07）

> 上游历史条目见 `CHANGELOG.md`。本文只记录 1.25.10 这一版的**改动明细与验证结论**，
> 供后续真机复核与回滚时对照。技术方案论证见 `docs/glass-inline-liquid-options.md`。

## 一句话

发现页书源名行接入**与底栏同一份 AGSL 数学**的液态玻璃观感（真折射 + 色散），
顶栏液态玻璃首次真正启用，**全程不录制任何 View 子树**，API<33 与任何异常都有无损兜底。

## 与 1.25.8 / 1.25.9 的关系（重要）

| 版本 | 做了什么 | 结果 |
|---|---|---|
| 1.25.8 | 行内直接用 `StableLiquidGlassView`，采样源绑列表 `RecyclerView` 自身（玻璃视图就在该 RV 的 item 里） | 库每帧 `source.draw()` 把玻璃自己再画一遍 → RenderNode 重入录制 → hwui abort，**切到发现页即 native 闪退** |
| 1.25.9 | **回退**行内液态管线，恢复静态模糊管线；新增 `LiquidGlassSourceGuard.selfOrAncestorContains` 采样源合法性守卫 | 稳定 |
| **1.25.10（本版）** | **重新设计**，不复用库的 Java 宿主，只复用其 AGSL 源码；采样源是**壁纸位图**，录制内容只有一条 `drawRect` | 观感回到液态，崩溃路径结构性不存在 |

**1.25.10 不是把 1.25.8 拿回来。** 两版的采样模型完全不同：

| | 1.25.8 | 1.25.10 |
|---|---|---|
| 内容源 | 每帧对 `RecyclerView` 整树录制 | 一次构建、按 key 缓存的降采样壁纸位图 |
| 每帧录制代价 | N 行 × 全屏子树 | N 行 × 一条 `drawRect` |
| 崩溃面 | 有（祖先/自身采样源 → 重入录制） | 无（路径上没有 `View.draw`） |
| 复用库的什么 | 整个 Java 宿主 | 只有 AGSL 源码（MIT） |

## 关键设计决定

1. **采样源只能是壁纸位图**：`ll_title` 背后没有列表内容（行与行不重叠，书网格在它下方），
   只有主题壁纸层。「真折射」在这里的正确实现是「共享静态纹理 + 位置采样」，不是「实时快照」。
2. **反射强度按行高标定**（决策 D2）：`band = min(预设, 0.42 × 行高)`，
   `amount = min(预设, 1.6 × band)`。0.42 与底栏 `pixelSafePill` 同一常量口径。
3. **着色器 tintAlpha 恒 0**：白色着色仍由既有 `tintPaint` 层负责，避免双重上色让
   「行可见度标定」与 tint 倍率滑杆失效。
4. **四级降级 + 两个正交的编译期总闸**（决策 D1/D4）：不新增偏好键；语义见下表；
   运行期用户兜底开关复用既有 `exploreGlassHardwareBlur`。

   | `ROW_LIQUID_ENABLED`（A2 真折射） | `ROW_PSEUDO_LIQUID_ENABLED`（A1 拟液态） | 结果 |
   |---|---|---|
   | `true`（默认） | `true`（默认） | API 33+ 走 A2；API < 33 走 A1 |
   | **`false`** | `true`（默认） | **全设备纯 A1** —— 用户做「A2 开/关」观感对比的对照组 |
   | `false` | `false` | **逐像素回到 1.25.9** 静态模糊渲染（最快回滚） |

   两个闸**正交**：关 A2 不会连带关 A1。A1 的调用条件是
   `rowPseudoLiquidEnabled(ROW_PSEUDO_LIQUID_ENABLED, drewLiquidGlass)` ——
   **只在本行没走成 A2 时叠加**（API<33 / A2 闸关 / A2 当帧失败），所以 API 33+ 且 A2
   成功的行只有「真折射 + 色散 + 既有 shell/rim/描边四层」，不会有拟液态双重叠加。

   > **故障位的恢复路径（务必分清）**：`RowLiquidRuntimeState.shaderFailed` 只活在
   > **进程内存**里，不落任何持久化存储（无 SharedPreferences / 无文件 / 无 MMKV）。
   > 用户**杀进程重开 App 会重新尝试 AGSL 编译**；若该机型/驱动确实编译不过，会在首帧
   > 再次置位（日志全进程仍只打一条，不刷屏）。所以「永久」的准确含义是
   > 「**本进程内剩余生命周期**」，跨启动不残留、跨升级不残留、也不会把其它机型的
   > 状态带过来。若某机型在真机复核中被发现持续失败，正确处置是记录机型号与 GPU
   > 并按需把两个编译期总闸打包置 `false`，而不是依赖运行期故障位。

5. **顶栏采样源修正**（对技术方案的偏差，见下）。

## 对技术方案的偏差（需要 review）

技术方案 §4-D 写顶栏采样源「只能是兄弟子树 `swipe_refresh_layout`（或 `fl_discover_books`）」，
**前半句是错的**：`fragment_explore.xml` 的层级是
`swipe_refresh_layout → FrameLayout → ll_modern_discovery → {fl_discover_books, top_bar}`，
即 `top_bar` 在 `swipe_refresh_layout` **内部**，它是**祖先**，传进去会复现 1.25.8 的同类 abort。
本版因此取 `fl_discover_books`（与 `top_bar` 平级）。书架页同理取 `view_pager_bookshelf`
（与 `top_bar` 同属根 `ConstraintLayout` 的孩子）。
`TopBarLiquidSourceTest` 用真实层级复刻把这条不变量锁死（`swipe_refresh_layout` 必须被拒）。

## 真机复核清单

1. **A2 是否生效（壁纸底）**：设置一张有明显纹理的壁纸 → 发现页 → 观察书源名行
   **左右两端 1~2px 内是否有「内容被向内弯折」的透镜感 + 极细彩边**；
   滚动时透镜感随行的屏幕位置变化（壁纸是静态的，所以观感是「透镜在壁纸上移动」，不会有文字弯折）。
2. **A2 在纯色底的表现（预期无变化）**：壁纸设为纯色/无背景图 → 行内只应看到 A1 的
   高光带 + 内阴影 + 彩边，**不应出现黑边、透明块或行消失**。
3. **A2 开关对比（对照组）**：把 `RowGlassLiquidSpec.kt` 的 `ROW_LIQUID_ENABLED` 置 `false`
   重新打包 → 此时**全设备走纯 A1**（A1 闸仍为 `true`），与 `true` 版在同一屏逐行对比：
   壁纸底应「一眼看出差异」（透镜感消失，只剩高光带/内阴影/彩边），纯色底应「几乎无差异」。
   想验证「逐像素等于 1.25.9」，再把 `ROW_PSEUDO_LIQUID_ENABLED` 也置 `false` 打包一次。
4. **顶栏液态（modern 布局）**：发现页 → 切到「现代/瀑布流」布局 → 上下滚动 →
   顶栏下方应出现**真实滚动内容被折射**的效果；切到 classic 布局 → 顶栏恢复实底（无玻璃）。
5. **顶栏回归**：书架页 → 覆盖式布局滚动 → 顶栏出现液态度；**全程不得闪退**
   （重点看 `adb logcat` 是否有 hwui abort / `RenderNode` 相关 native crash）。
6. **降级路径**：API 30 模拟器 → 行与顶栏走 A1/实底，无异常；
   开发者选项「强制 GPU 渲染关闭」或截图场景（软件 Canvas）→ 不得出现黑块。
7. **性能**：`adb shell dumpsys gfxinfo io.legado.app framestats` 对比
   `ROW_LIQUID_ENABLED` 开（A2+A1）/ 关（纯 A1）/ 双闸全关（1.25.9）三组滚动 10s，
   验收阈值：janky% 增幅 ≤ 1.5pp、95th 帧耗时增幅 ≤ 1.5ms。
   另看「首次滚动 vs 二次滚动」的帧耗时差（`RuntimeShader` 首次编译开销）。
8. **日志**：`adb logcat -s ExploreGlass:*` 应**为空**（无降级日志）；
   若出现「行内液态玻璃降级为静态管线（进程内持久）」说明该设备 AGSL 编译或绘制失败
   （全进程只打一条，之后不再刷屏），需记录机型号与 GPU。

## 回滚

| 层级 | 手段 |
|---|---|
| 编译期（只关 A2） | `ROW_LIQUID_ENABLED = false` → 全设备纯 A1（A2 观感对比的对照组） |
| 编译期（全关） | 两个总闸都置 `false` → 行内**逐像素回到 1.25.9**（A2 + A1 全关） |
| 运行期（用户） | 「全局毛玻璃效果 → 硬件模糊」关掉 → 走静态管线 |
| 顶栏单独回滚 | 两个宿主改回 `setBackdropBlur(null)`，不影响行内 |
| 版本 | 本版无数据迁移、无偏好键、无布局改动，`git revert` 即回到 1.25.9 |
